# Dulces Delicias

Proyecto web estático para una tienda de dulces con varias páginas HTML y scripts JavaScript que realizan manipulación del DOM.

## Descripción

Este proyecto usa HTML, CSS y JavaScript para crear una experiencia de tienda en línea sencilla. Los archivos JavaScript actualizan el contenido de las páginas en tiempo real, interactúan con formularios y modifican elementos del DOM para mostrar productos, gestionar el carrito, iniciar sesión y registrar usuarios.

## Estructura del proyecto

- `adminPedidos.html` - Página de administración de pedidos
- `carrito.html` - Página del carrito de compras
- `home.html` - Página principal
- `login.html` - Página de inicio de sesión
- `nuestrosProductos.html` - Página de productos disponibles
- `registroClientes.html` - Página para registrar clientes
- `registroProductos.html` - Página para registrar productos
- `CSS/` - Estilos del proyecto
- `img/` - Imágenes usadas en el sitio
- `js/` - Scripts JavaScript que manipulan el DOM

## Manipulación del DOM

Los archivos JavaScript en `js/` realizan principalmente:

- Inserción dinámica de contenido en la página
- Lectura y escritura de valores en formularios
- Actualización de listas de productos y pedidos
- Control de eventos de botones y formularios
- Mostrar/ocultar secciones según acciones del usuario

## Archivos JavaScript principales

- `js/carrito.js`
- `js/crudPedidos.js`
- `js/crudProductos.js`
- `js/crudUsuarios.js`
- `js/home.js`
- `js/login.js`
- `js/logout.js`
- `js/productos.js`
- `js/registroClientes.js`

## Uso

Abrir cualquiera de las páginas HTML en el navegador. Los scripts se encargan de la interacción y la manipulación del DOM sin necesidad de un servidor.

## Nota

El proyecto es un ejemplo de cómo usar la manipulación del DOM con JavaScript para manejar comportamiento dinámico en una aplicación web estática.
